# JavaScript Basics Course - Injaz Club

<img src="https://upload.wikimedia.org/wikipedia/commons/6/6a/JavaScript-logo.png" alt="JavaScript Logo" width="150">

Welcome to the **JavaScript Basics Course**! This repository contains all the materials and resources for the course organized by **Injaz Club** and created by **Nasreddine BOUDELLAL**. Whether you're a complete beginner or looking to refresh your skills, this course will help you learn the fundamentals of JavaScript programming step by step.

---

## 📚 Course Overview

This course is designed to teach you **JavaScript from the ground up**. By the end of the course, you will be able to:

- Understand JavaScript syntax, variables, and data types.
- Work with objects, arrays, and functions.
- Use operators and control structures effectively.
- Master advanced topics like object-oriented programming, array methods, and error handling.
- Build a strong foundation for further programming learning.

## 🛠️ How to Use This Repository

1. **Clone the Repository:**
   - Open your terminal and run:
     ```bash
     git clone https://github.com/nasreddine19/JavaScript-Basics-Injaz.git
     ```

2. **Navigate to the Folder:**
   - Go to the repository folder:
     ```bash
     cd JavaScript-Basics-Injaz
     ```

3. **Open the Files:**
   - Use a code editor like [VS Code](https://code.visualstudio.com/) to open and explore the files.

4. **Run the Code:**
   - Use Node.js to run the JavaScript files.
